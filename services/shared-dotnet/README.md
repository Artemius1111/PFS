# shared-dotnet

Спільна бібліотека `ProjectHub.ServiceDefaults` для всіх C#-сервісів: перевірка JWT, формат помилок, health, публікація і споживання подій RabbitMQ.

Власник — C#-розробник. Задачі: CS-02, CS-04.

Правило: сюди потрапляє тільки інфраструктурний код, який однаковий для всіх сервісів. Бізнес-логіка конкретного сервісу тут не живе.
