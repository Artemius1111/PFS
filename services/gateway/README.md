# gateway

Єдина точка входу в систему.

| | |
|---|---|
| Мова | C# · .NET 10 |
| Ключові бібліотеки | YARP, ASP.NET Core Authentication (JwtBearer), Rate Limiting |
| Порт | 8080 |
| База даних | немає |
| Власник | C#-розробник |
| Задачі | CS-01, CS-02, CS-12 |

## Що робить

- Маршрутизує запити до сервісів (таблиця в `docs/API.md`).
- Перевіряє JWT до того, як запит піде далі.
- CORS для фронтенду, rate limiting, `X-Correlation-Id`.
- Прокидає WebSocket для SignalR-хабу дошки.
